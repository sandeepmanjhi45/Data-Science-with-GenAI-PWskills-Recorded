# Types of Apps (Quick Notes)

## Web, mobile and desktop

| | Web App | Mobile App | Desktop App |
|---|---------|------------|-------------|
| Runs on | Browser | Phone or tablet | PC or laptop |
| Install | Not needed | App store | Installer |
| Example | Gmail, amazon.in | Amazon app | MS Word, MS Paint |

## Front-end vs back-end
- **Front-end:** what the user sees. Uses HTML, CSS and JavaScript, plus React, Angular or Vue.
- **Back-end:** logic, database and server. Uses Python, Node.js, Java, PHP or Go, plus databases like MySQL, PostgreSQL and MongoDB.
- **APIs (REST, GraphQL)** connect the front-end to the back-end.

## Remember
- amazon.in is a **web app**, and MS Paint is a **desktop app**.
- Web apps need no installation, while mobile and desktop apps do.
